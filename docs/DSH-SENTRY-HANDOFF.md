# DSH 接入 Sentry 前的基线与边界

日期：2026-09-17。本文件所属本地提交是接入前的完整功能恢复点，版本0.2.3；不要退回旧0.2.2代码来撤销Sentry。

## 当前已保存的功能

- 阅读/听力点击单词、本地词典优先、显式AI解释、中文默认隐藏、多义项展开。
- 网址文章及离线图片、音频直链、支持的视频页面提取音频；组件首次自动下载、校验、取消及复用。
- 重建缺口修复：格式化正文查词、成功导入后关闭弹窗、带标题图片、切词后折叠其他义项。
- BBC文章独占一段的连续下划线显示为受限宽度分隔线，不改存储正文。
- 本轮133项测试通过、1项条件跳过，类型检查/构建通过；真实视频网络测试本轮未重跑。早前真实视频来源仅实测Wikimedia，不代表其他站点均兼容。

## 开始接入之前

1. 读取本文件、CONTEXT.md和docs/adr；检查 `git status --short`、`git log -3 --oneline`，记录当前完整提交哈希。
2. 若基线之后还有未提交改动，先识别归属并保留，不可当作Sentry改动删除；不能判断时暂停询问用户。
3. 推荐在独立功能分支进行Sentry接入。分支名称、SDK选型及发送真实事件的授权由用户在该任务中确定。

## 修改与回退边界

- 只增加用户批准的Sentry能力；保持上述产品功能、测试和UI。此交接不是自动批准事件发送、Replay采集或发布。
- 禁止用 `git checkout --`、`git restore`、`git reset --hard` 或清理未跟踪文件的方式整文件撤销混合改动。
- 撤销Sentry时逐段撤销本次补丁；如需撤销独立提交，先说明目标提交、影响与工作区状态并取得确认。不得按测试接口重写已有大文件代替恢复原文。
- 不把用户文章、音频、逐字稿、单词本、API Key、环境配置和完整本机路径发送到遥测或提交到Git。
- 保持 `.scratch/`、环境文件、state.json、ai-services.json、媒体/缓存等忽略规则；禁止强制添加。
- 不执行桌面更新、Git推送或Release上传，除非该任务另获明确授权。

## 接入后的验证与交付

- 先保留基线测试结果，接入后运行全量测试和构建；不得删测试来消除失败。
- 回归格式化查词、带标题离线图片、导入成功/失败/取消/返回资料库、多义项切换、主音频播放。
- 独立临时用户目录测试，不使用正式学习数据做演示或Replay。
- 区分配置完成、事件实际收到、页面实际展示、用户验收；不能把其中一项当作全部完成。
- 交付列出修改文件、测试结果、是否发送过事件、遗留问题及回退方法。
