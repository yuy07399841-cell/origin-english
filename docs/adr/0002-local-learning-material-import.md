# 网址是材料入口，导入结果是本地学习材料

为免去先在浏览器下载再手动导入的操作，同时保留离线学习能力，文章网址导入生成包含正文和正文图片的本地文章并保留来源链接，而不是仅收藏网页地址或嵌入整个网站。视频及音频网址只生成现有听力模块使用的本地音频，不保存视频画面；转写是导入后的手动步骤，避免每次下载都启动长时间处理。

## Consequences

- 本地材料需要占用磁盘空间；正文图片单独失败不阻止正文导入，但须提示，不能把未保存的图片标成已离线可用。
- 第一版只处理单篇文章或单个音视频，不导入合集；只支持能获取的公开内容，不承诺所有网站可用，也不扩展到登录、付费或访问限制绕过。
- 获取失败时明确告知并保留本地文件导入；正文获取失败不创建空文章。导入成功与转写成功是不同状态。
- 网站适配、下载组件、资源限制和清理策略仍需工程验证，本记录不表示这些技术选型已确定或网址导入已实现。
